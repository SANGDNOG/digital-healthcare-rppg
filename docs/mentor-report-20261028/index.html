1. 목표와 현재 도달한 단계

최종 목표는 웹캠으로 추정한 생리적 변화와 개인의 휴식 기준선·자가보고를 함께 관찰하여 스트레스 반응을 자가 모니터링하는 것이다. 현재는 이 목표의 선행 단계인 심박 추정과 신호 품질 관리, 3분 실험 기록 도구를 구현하였다. 스트레스 점수나 진단을 산출하는 시스템은 아직 검증하지 않았다.

2. 1차 계획·멘토 의견 반영

1차 계획은 개인 기준선과 스트레스 과제 데이터 활용을 포함하였다. 멘토 의견에 따라 조명·각도·움직임 등 측정 조건을 기록하고, 결과를 접촉 센서와 교차 확인하며, 사람별 차이를 분리해 평가하는 방향을 유지한다. 이번 단계에서는 데이터 확보와 품질 확인이 선행되어야 하므로 심박 추정의 작동 범위를 먼저 점검하였다.

계획서의 UBFC-Phys와 이번 실험의 UBFC-rPPG는 서로 다른 데이터셋이다. 이번 심박 평가 자료를 스트레스 정답 데이터로 사용하지 않았으며, UBFC-Phys를 활용한 스트레스 과제 학습·평가는 미실시 상태이다.

심박수를 먼저 확인하는 이유

얼굴의 미세한 색 변화에서 맥파를 얻지 못하면 이후의 스트레스 반응 비교도 신뢰할 수 없다. 다만 심박 변화에는 자세, 호흡, 운동, 긴장 등 여러 원인이 있으므로 심박 상승만으로 스트레스를 확정하지 않는다. 품질을 통과한 심박 변화와 조건 기록·자가보고를 함께 해석한다.

무엇을 바꾸었는가

기존 방식은 얼굴 후보가 둘 이상이면 해당 프레임을 제외했다. 개선 방식은 직전 얼굴의 위치·크기와 이어지는 후보가 하나일 때 이를 선택하고, 후보가 모호하면 계속 보류한다. 신호 품질 기준은 출력 수를 늘리기 위해 완화하지 않았다. 이 변경으로 subject4에서 출력 가능한 창이 0개에서 19개로 증가하였다.

무엇이 개선되었다고 말할 수 있는가

확인한 개선은 측정 가능한 구간의 증가이다. 전후 공통 비교 가능 46개 창에서는 추정치와 오차가 동일했다. 따라서 전체 평균 오차의 차이를 정확도 향상으로 해석하지 않는다. GREEN 방식은 10/101개, POS는 67/101개 창을 출력했으나 공통 비교 가능 창이 7개로 적어 일반적 우월성을 단정하지 않는다.

남아 있는 실패와 해석의 한계

개선 후에도 영상 심박은 34/101개 창에서 보류되었다. 직접적인 보류 사유는 맥박 후보 주파수 주변에 에너지가 충분히 집중되지 않는 것이며, 움직임·조명·피부영역 오염 중 어느 원인이 지배적인지는 아직 분리하지 못했다. 보류를 0 BPM으로 처리하거나 실패 구간을 숨기지 않는다.

20초 창은 1초 간격으로 생성되어 95% 중첩된다. 101개의 독립 실험이나 충분한 피험자 수를 확보한 결과가 아니다. 영상·접촉 신호의 시작 0초가 같다고 가정했으며 정확한 시간 대응은 독립 검증하지 못했다. 따라서 이 결과는 예비 비교이며 의료 정확도·스트레스 판별 성능을 의미하지 않는다.

4. 스트레스 목표로 이어지는 다음 실험

웹캠 전송 병목을 줄이기 위해 촬영 컴퓨터에서 분석하는 경로를 마련했다. 사용자 화면에서 약 15회/초의 응답과 심박 출력 사례가 확인되었지만, 이는 작동 관찰이며 접촉 센서로 검증한 정확도는 아니다. 실제 3분 실험 완료·반복 비교는 다음 단계이다.

구간실행 내용과 기록
휴식 60초같은 조명·거리·자세로 앉아 기준 상태 기록
무음 암산 60초1000에서 7씩 빼기. 말하기·큰 움직임은 피하고 실제 수행 여부 기록
회복 60초다시 휴식. 종료 후 구간별 주관적 부담을 0~10으로 회상 평가

도구는 구간 경계에 걸친 분석창과 저품질 분석을 비교에서 제외한다. 완전히 끝난 각 구간에 중복되지 않은 유효 분석 결과가 30개 이상 있을 때만 심박 중앙값 차이를 비교한다. 이 결과들은 서로 중첩되므로 독립 표본 30개를 뜻하지 않는다. 자가보고 역시 회상값이며 스트레스의 객관적 정답으로 취급하지 않는다.
