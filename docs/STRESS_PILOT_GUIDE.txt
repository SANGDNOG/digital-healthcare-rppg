3분 스트레스 반응 관찰 실험 안내 (2026-10-28)

목적: 도구가 구간별 생리 변화를 기록할 수 있는지 확인합니다. 스트레스를 진단하거나 점수의 정확도를 검증한 실험이 아닙니다.

1. 촬영 컴퓨터에서 rppg.live를 실행하고 같은 컴퓨터의 루프백 주소를 엽니다. 카메라 시작은 직접 선택합니다.
2. 조명·거리·자세를 일정하게 두고 얼굴 검출, 최근 분석 시각, 신호 품질 표시를 확인합니다. 심박이 안 나올 때 0 BPM으로 기록하지 않습니다.
3. 3분 실험 시작 후 화면 안내를 따릅니다. 휴식 60초 → 말없이 1000에서 7씩 빼는 암산 60초 → 회복 60초입니다.
4. 종료 후 각 구간의 부담을 0~10으로 회상 평가하고 수행 여부·특이사항을 기록합니다. 수면·카페인 등 해석에 영향을 주는 조건은 필요한 범위에서 기록합니다.
5. JSON과 CSV를 내보내고 완료 여부, 각 구간의 유효 분석 수·보류 사유를 확인합니다. 원본 개인별 자료를 공개 GitHub에 올리지 않습니다.

비교 규칙: 끝난 각 구간에 중복 이벤트를 제거한 유효 분석이 30개 이상인 경우 심박 중앙값 변화를 비교합니다. 경계에 걸친 20초 창과 품질 미달 결과는 제외됩니다. 결과는 중첩창이므로 독립 표본 30개를 뜻하지 않습니다. 부족하면 수치를 억지로 채우지 않고 보류합니다.

팀에 전달할 것: 실행 완료/미완료, 구간별 유효 수, 심박 변화의 관찰 여부, 실패 사유, 다음에 통제할 조건. 심박 변화나 자가보고 하나만으로 스트레스를 확정하지 않습니다.
