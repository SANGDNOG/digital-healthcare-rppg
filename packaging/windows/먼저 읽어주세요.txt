Windows 팀원용 rPPG · 먼저 읽어 주세요

1. 받은 ZIP을 마우스 오른쪽으로 눌러 [모두 압축 풀기]를 선택합니다. ZIP 안에서 바로 실행하면 안 됩니다.
2. 압축을 푼 폴더의 [실험 시작.cmd]를 실행합니다. 파일명이 보이지 않으면 start.cmd를 실행해도 같습니다.
3. 최초 실행에는 인터넷이 필요합니다. Python과 분석 라이브러리를 폴더 안에 설치하므로 몇 분 걸릴 수 있습니다. 기존 Python 설치나 관리자 권한, GitHub·SSH 로그인은 필요하지 않습니다. 설치 중 검은 창을 닫지 마세요.
4. 브라우저가 열리면 [3분 예비 실험 시작]을 누릅니다. 카메라 권한은 직접 허용합니다. 창이 자동으로 안 열리면 실행 창에 나온 http://127.0.0.1:숫자/ 주소를 Chrome이나 Edge에서 엽니다. 주소의 숫자는 실행할 때 달라질 수 있습니다.
5. 휴식60초 → 말없이 1000에서7씩 빼는 암산60초 → 회복60초를 진행합니다. 얼굴을 밝게 하고 같은 자세를 유지하세요. 실험 중 탭을 바꾸거나 창을 최소화하지 마세요.
6. 끝나면 각 구간에서 느낀 부담0~10을 입력하고 [전체 JSON 내려받기]와 [요약 CSV 내려받기]를 모두 누릅니다. 브라우저 다운로드 폴더에서 두 파일을 확인하세요. 새로고침·탭 닫기 전 저장해야 합니다.
7. 팀장에게 JSON·CSV와 완료/중단 여부, 조명·움직임·기기 조건을 전달합니다. 자동으로 전송되지 않습니다. 개인별 기록은 공개 GitHub에 올리지 마세요.
8. 끝난 뒤 실행 창에서 Ctrl+C를 누릅니다. 다음부터는 같은 폴더의 같은 실행 파일을 사용하세요. 실행 중에는 폴더를 옮기거나 지우지 마세요.

기존 결과 보기
reports 폴더의 index.html을 열면 중간 결과 보고서를 읽을 수 있습니다. PDF로도 포함했습니다. feedback-request.html은 번호형 멘토 요청사항입니다. 이 자료를 먼저 읽고 현재 확인한 결과와 아직 검증하지 못한 부분을 구분해 주세요.

필요 환경
Windows10/11 x64, 웹캠, Chrome 또는 Edge, 최초 설치 인터넷, 쓰기 가능한 폴더와 약1GB 이상의 여유 공간을 권장합니다. Windows ARM/32비트는 이 패키지의 지원 대상이 아닙니다. 학교 보안 정책이 실행을 차단하면 우회하지 말고 오류 문구를 팀장에게 알려 주세요. 경로가 너무 길어 오류가 나면 문서 폴더 등 짧은 경로에 압축을 다시 풀어 실행하세요.

측정이 안 되는 경우
첫20초는 신호를 모읍니다. 얼굴이 보이더라도 맥박 신호가 약하면 결과를 보류합니다. 최근 분석 시각·측정 속도·얼굴 후보·경고 문구를 확인하세요. 실패한 실행도 저장해 주세요. 값을 강제로 채우거나0 BPM으로 바꾸지 않습니다. 카메라를 쓰는 다른 앱을 닫고 Windows/브라우저 권한을 확인할 수 있습니다.

자료가 저장되는 곳
설치 파일은 패키지의 .python, .venv 및 .cache 폴더에 생깁니다. 실험 기록은 탭 메모리에만 있다가 사용자가 다운로드할 때 브라우저 다운로드 위치에 저장됩니다. 얼굴 영상·소리는 파일로 저장하지 않습니다. 프레임은 본인 컴퓨터의 루프백 분석 서버에서 처리합니다.

해석 범위
같은 프로그램을 쓴다고 사람마다 같은 심박수나 품질이 나오지는 않습니다. 이 도구는 심박 변화와 본인이 느낀 부담을 살펴보는 예비 실험이며, 스트레스 점수나 의료 진단을 제공하지 않습니다. 완료된 각 단계에 유효 분석30개 이상일 때만 비교하며,20초 분석창은 서로 겹치므로 독립 표본30개를 뜻하지 않습니다.
