처음 실행하는 팀원을 위한 안내

이 화면은 본인 컴퓨터에서 분석합니다. 팀장 컴퓨터나 SSH 연결은 필요하지 않습니다. 카메라는 직접 시작을 눌렀을 때만 켜집니다.

  1. 카메라가 있는 Windows 10/11 64비트 PC에서 Chrome 또는 Edge로 사용합니다. 얼굴이 밝게 보이도록 조명을 맞추고, 화면 앞에 한 명만 앉습니다.
  2. 익명 코드와 조건 메모를 적습니다. 예: P02, 책상 조명, 약 50cm, 안경 착용. 이름·학번은 적지 않습니다.
  3. 3분 예비 실험 시작을 누르고 카메라 사용을 허용합니다. 휴식 60초 → 말없이 1000에서 7씩 빼기 60초 → 다시 휴식 60초입니다.
  4. 실험 중 탭을 바꾸거나 창을 최소화하지 말고 같은 자세를 유지합니다. 화면의 단계 안내를 따릅니다. 잠깐 값이 안 나와도 시간을 임의로 건너뛰지 않습니다.
  5. 끝나면 휴식·암산·회복에서 느꼈던 부담을 각각 0~10으로 입력합니다. 느끼지 못했으면 0, 응답하지 않을 경우 빈칸으로 둡니다.
  6. 전체 JSON 내려받기와 요약 CSV 내려받기를 모두 눌러 저장합니다. 브라우저의 다운로드 위치에 저장되며 새로고침하거나 탭을 닫기 전에 받아야 합니다.
  7. 기록이 저장됐는지 확인한 뒤 창을 닫습니다. 실행 창에서 Ctrl+C를 눌러 서버를 종료합니다.

팀장에게 전달할 것

저장한 JSON·CSV, 완료/중단 여부, 당시 조명·움직임·기기 조건, 화면에 나온 보류 사유를 전달해 주세요. 자동 전송 기능은 없습니다. 파일에는 생리 추정값과 자가보고가 있으므로 공개 GitHub에는 올리지 않습니다.

값이 안 나올 때

첫 20초는 신호를 모읍니다. 이후에도 품질이 낮으면 심박수를 표시하지 않습니다. 최근 분석 시각이 갱신되는지, 얼굴 후보가 1개인지, 측정 속도와 경고를 확인합니다. 실패한 실행도 의미 있는 결과이므로 보류를 0 BPM으로 바꾸지 말고 그대로 기록합니다. 카메라가 안 열리면 다른 카메라 앱을 닫고 Windows·브라우저의 카메라 권한을 확인합니다.

이 실험은 스트레스 진단이 아닙니다. 심박 변화와 주관적 부담을 관찰하는 연구용 예비 실험입니다. 영상과 소리는 파일로 저장하지 않으며, 프레임은 본인 PC의 루프백 분석 서버로 전달됩니다.
